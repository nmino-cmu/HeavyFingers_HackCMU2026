# Shared packet (every ideation agent)

HackCMU 2026. Fri 9pm–Sat 4pm EDT submit (~19h). Team ≤4. From scratch (brainstorm OK). Any language/AI. **One** track + 50-word why. **3 min** talk+demo.

## Tracks (pick one)

Optimization — “perhaps optimize something?”  
Traveling — “what does traveling mean to you?”  
Multiplayer — “meet people / touch grass”  
Food — “Yummy.”  
Theme fit is judged (Relevance). Sparse track may only award 1st.

IFM is an **optional extra prize**, not a required fifth track.

## Judging

Originality. Technical difficulty (**real tech vs ChatGPT wrapper**). Demo quality (clear, <3 min). Usefulness. Relevance (track only).

## Prizes (stackable)

Grand: HRT poker set.  
Track 1/2/3: mini projector+Jump AirPods Pro / Visa swag / keyboard+keychain.  
IFM: Kindle Lite (use K2/IFM tools).  
Cursor: keyboards (bar unknown — do not assume “we coded in Cursor” wins).  
Sandia Cyber: ANC AirPods (real security mechanism; no live third-party attacks).  
People’s Favorite: Ticket to Ride.  
Best Design: Fujifilm QuickSnap.

MLH Best Use (not track-locked):  
- Gemini API → swag. Use the API. Distinctive: multimodal / long context / tools — not a generic chat. `gemini-3.8-flash`.

No prizes: Jane Street, Citadel, Microsoft, Adobe, Roblox, Querit.

Do **not** copy last year’s grand-prize shape. Do **not** invent extra prizes.

## Bolt / wrapper

Delete the sponsor, replace with the cheapest substitute. If the 3-min demo does not change, it is bolted.  
Delete the LLM. If nothing remains, it is a wrapper — dead.

## Banned products (the *product*, not the word)

AI-for-X chatbot/summarizer/study buddy/resume coach/therapy bot. Fridge→recipe. Itinerary/travel buddy. Calendar optimizer. Kahoot/Jackbox clone. Uber/Tinder for X. Split-the-bill. Carbon tracker. Voice that only reads the last LLM sentence. “Deployed on Vultr.” Auth0 as login only. Atlas as users table only. Chain as points. Campus-only dining/class apps.

## Demo bar

Judge understands in <30s. Visible before→after. One wow the room can see. Survives a 20s model stall. Reset ≤60s.

## Hours

4 people. Reserve last 4h for polish/submit/demo. Core loop must work by Saturday morning. If it needs hardware you do not have, or a paid API, or a dataset you cannot make in 1h — do not propose it.

## Score 0–10 integers

U usefulness, T tech, O originality, D demo, Rel track relevance.  
F feasibility, R reliability, P polish, S scope efficiency.  
N field-novelty, M memorable, J 30s comprehension, W wow, K fraction of work the judge can see.  
Per sponsor: E official eligibility, C centrality, X distinctive capability, B bolted (10=shameless).  
A multi-prize surface, G grand path, H team fit, Y story coherence.  
Risks higher=worse: I, API, DR, SR, CR wrapper, ER explanation, AR already-exists, BR boring.

p_prize buckets only: 0, 0.02, 0.05, 0.10, 0.20, 0.35, 0.50.
