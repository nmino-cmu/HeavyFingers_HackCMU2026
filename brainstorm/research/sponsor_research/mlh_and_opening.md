# Sponsor research (eligibility bars)

Pulled from MLH HackCMU prize page (re-fetched Fri Sep 11 night), partner hubs, opening deck. Not a substitute for `competition_ground_truth.md`.

## Gemini

- Official: use Gemini API. Examples are chatbot / summarize / generate — **those examples are the losing prior** if that is all you do.
- Distinctive (our bar): multimodal in, structured out, long context, tools, live. Photo-in / video-in that changes the UI.
- Key: AI Studio. Model: `gemini-3.8-flash`. Free. Cloud $300 will not pay this.

## ElevenLabs

- Official: “fully autonomous audio,” project has a voice.
- Distinctive: voice *is* the loop (character, live conversation, accessibility), not TTS on the last sentence.

## Solana

- Official: fast cheap txs; games/social; DEX; supply/identity/payments.
- Must: **devnet** transaction or program the judge can see (signature / wallet).
- Ornamental “we have a wallet button” fails our bar.

## Vultr

- Official: compute, one-click, Cloud GPUs, infra not the bottleneck.
- Distinctive: GPU job, always-on agent, websocket world, something a laptop cannot fake in the demo.
- Credits: $100 via MLH Coach + giftcode link.

## Auth0

- Official: **any** Auth0 API. Login/MFA/passwordless OR Auth0 for AI Agents.
- Distinctive: permission boundary the demo *breaks* if Auth0 is removed (delegation, Token Vault, role-gated action).
- Trap: `hackp.ac/auth0-signup` is a newsletter.

## MongoDB Atlas

- Official: build using Atlas.
- Distinctive: evolving schema, geo, vectors, live sync — not `users` collection only.

## IFM

- K2 six open models, Jais, PAN. Workshop TEP 1403 Fri 9–10pm.
- Prize: Kindle Lite. Bar unstated. Treat like MLH: K2 must be load-bearing.

## Cursor / SpaceXAI

- Workshop: Cursor, Grok Imagine, Grok Bot (resume/portfolio/jobs pitch — that is the *workshop*, not necessarily the prize rubric).
- Prize: keyboards. Eligibility UNKNOWN — do not assume “we used Cursor to code” wins.

## Sandia

- Cybersecurity prize. Extra rules UNKNOWN. Need a real security mechanism in the demo, not a theme sticker.

## Querit / Jane Street / Citadel / Microsoft / Adobe / Roblox

- No opening prize. Do not target.
