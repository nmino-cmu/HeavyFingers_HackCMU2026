## Jury recommendation and reversal condition

Build **Ask Once** only after this early proof succeeds:

1. A controlled handwritten donation-label fixture produces Gemini structured evidence tied to visible source text.
2. A conservative allocation allows only one of four households.
3. The app selects a single human question.
4. Entering a staff-confirmed answer raises the eligible count without inventing an ingredient fact.

If this fails at the early checkpoint, switch to **StaleMap** only if a real Atlas-backed report changes confidence and recomputes a route. If both Gemini directions fail, choose CycleClear only after four pre-funded devnet wallets complete one settled and one rejected cycle end-to-end.
